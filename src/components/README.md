# components

أجزاء تتكرر في أكثر من صفحة. كل component في مجلد باسمه، وأول الملف تعليق يشرحه، وأنماطه في ملف CSS بجانبه (`Header/header.css`) يستورده `src/styles/index.css`، وسلوكه، إن كان له، في ملف TypeScript بجانبه (`MegaMenu/mega-menu.ts`) يشغّله `src/scripts/main.ts`.

## layout: إطار كل صفحة

| Component                                                  | ما هو                                                                                                      |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `Header/Header.astro`                                      | الشريط العلوي: الشعار، الأقسام (الخدمات · المشاريع · الأكاديمية · للشركات · من أنا)، اللغة، «اطلب خدمة»    |
| `MegaMenu/MegaMenu.astro` · `MegaPanel.astro`              | القوائم المنسدلة تحت الشريط (الخدمات، من أنا)، بقواعد عرض واحدة لكل لوحة                                   |
| `MobileSheet/MobileSheet.astro`                            | قائمة الموبايل                                                                                             |
| `LanguageMenu/LanguageButton.astro` · `LanguageList.astro` | زر اللغة، وقائمة اللغات بثلاث صيغ (منسدلة، في قائمة الموبايل، في الفوتر)، كل لغة رابط إلى الصفحة نفسها بها |
| `SoonTip/SoonTip.astro`                                    | قسم في مكانه النهائي لكنه مطفأ، مع ملاحظة «قريباً»                                                         |
| `Footer/Footer.astro`                                      | الفوتر بثلاث طبقات                                                                                         |
| `Dock/Dock.astro`                                          | زر الطلب السفلي على الموبايل                                                                               |
| `SkipLink.astro`                                           | رابط «تخطَّ إلى المحتوى»                                                                                   |

## ui: قطع صغيرة

| Component                      | ما هو                                                        |
| ------------------------------ | ------------------------------------------------------------ |
| `Icon/Icon.astro` · `icons.ts` | كل أيقونات الموقع بـ SVG                                     |
| `Logo/Logo.astro`              | شعار cod، رابطاً للرئيسية                                    |
| `Pill/Pill.astro`              | زر الفعل المدوّر: `ink` `snow` `line`                        |
| `ArrowLink/ArrowLink.astro`    | رابط نصي ينتهي بالسهم (اطلب هذا الحل، التالي، أسئلة الأبواب) |
| `CheckList/CheckList.astro`    | قائمة «يشمل» تحت كل حل                                       |
| `ScriptData/ScriptData.astro`  | يمرّر نصوص السلوك ببيانات JSON لا تُرسم                      |

## effects: المؤثرات

| Component                       | ما هو                                                              |
| ------------------------------- | ------------------------------------------------------------------ |
| `Aura/Aura.astro`               | الهالة: ضوء ناعم بحبيبات، بشكل مسمّى (`content` `ai` `software` …) |
| `LiquidLight/LiquidLight.astro` | الضوء السائل خلف الأبواب الثلاثة وفي «اعمل معي»                    |
| `Spectrum/Spectrum.astro`       | شريط التدرّج من الأسود إلى الفاتح، أو معكوساً قبل الخاتمة          |
| `Echo/echo.css`                 | الصدى خلف العناوين (`data-echo`): أنماط فقط، والسلوك في `echo.ts`  |

## sections: أقسام تتكرر

| Component                     | ما هو                                                                 |
| ----------------------------- | --------------------------------------------------------------------- |
| `PageHero/PageHero.astro`     | الشاشة الأولى للصفحات الداخلية: الضوء خلف، والنص أمام                 |

## forms: نموذج الطلب («اطلب خدمة» و«اعمل معي»)

| Component                                                     | ما هو                                                                         |
| ------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| `RequestForm/RequestForm.astro`                               | القسم كله: العنوان (slot)، الأسئلة (slot)، ثم الأجزاء المشتركة                |
| `ChoiceGroup/ChoiceGroup.astro` · `Choice.astro`              | سؤال بخيارات                                                                  |
| `Field/Field.astro`                                           | حقل نص أو مربع كتابة، مع التلميح وسطر الخطأ                                   |

| `ErrorSummary/ErrorSummary.astro`                             | قائمة الحقول التي تحتاج تصحيحاً                                               |
| `MessagePreview/MessagePreview.astro` · `MobilePreview.astro` | الرسالة كما ستصل: على الموبايل بجانب النموذج، ومطوية تحته على الشاشات الصغيرة |
| `SendBar/SendBar.astro`                                       | زر الإرسال باسم القناة، والقناة الأخرى، والسطر الصغير                         |
| `DoneState/DoneState.astro`                                   | ما بعد الإرسال                                                                |
