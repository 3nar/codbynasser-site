# الخطوط

ملفات الخطوط الأربعة، يخدمها الموقع من نفسه بدل Google Fonts، فلا تذهب عناوين الزوار إلى Google، وتسمح سياسة CSP بالخطوط من الموقع وحده.

لا تُعدَّل يدوياً: يكتبها `scripts/fonts.ts` مع `src/styles/fonts.css` من ورقتي Google نفسيهما (`npm run fonts`). كل ملف لنص واحد (عربي، لاتيني، سيريلي...)، والمتصفح لا يحمّل إلا ما تحتاجه الصفحة.

| العائلة              | الأوزان                       | تُستعمل في          |
| -------------------- | ----------------------------- | ------------------- |
| Tajawal              | 300، 700، 800                 | الصفحات العربية     |
| IBM Plex Sans Arabic | 400، 500                      | الصفحات العربية     |
| Onest                | 400 إلى 800 (متغيّر)          | الإنكليزية والروسية |
| Source Serif 4       | 300 إلى 600، مائل وقائم، opsz | الإنكليزية والروسية |

الرخصة: الأربعة تحت [SIL Open Font License 1.1](https://openfontlicense.org)، وهي تسمح باستضافتها ونشرها مع الموقع، ونصّ حقوق كل خط محفوظ داخل ملفه.
