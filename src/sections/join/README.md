# اعمل معي (`/join/`)

أشكال الضوء السائل في الشاشة الأولى في `JoinHero/join-hero.ts`، والنموذج يحرّكه `components/forms/RequestForm/request-form.ts`.

| القسم       | ما فيه                                                                                                 |
| ----------- | ------------------------------------------------------------------------------------------------------ |
| `JoinHero/` | الشاشة الأولى في الضوء السائل                                                                          |
| `Fields/`   | المجالات التي أحتاجها، من `src/content/join-fields/`: لوحة بطاقات، لكل مجال رسمة (`FieldFigure.astro`) |
| `Apply/`    | «عرّفني بنفسك»: `components/forms/RequestForm` بالتخصص (القائمة نفسها)، والاسم، ورابط الأعمال، والنبذة |
