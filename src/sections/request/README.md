# اطلب خدمة (`/request/`)

النموذج يحرّكه `components/forms/RequestForm/request-form.ts`: يقرأ الرابط (`src/lib/prefill/`)، ويكتب الرسالة (`src/lib/message/`). ما يمكن أن يختاره الرابط (مشكلات كل خدمة، وأسماء المشاريع) يمرّره `ServiceChoice` من المحتوى.

| القسم             | ما فيه                                                                                                                 |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `ServiceRequest/` | الصفحة كلها: `components/forms/RequestForm` بعنوانها، والخدمة، و«احكِ لي عن مشروعك»، والاسم                            |
| `RequestHeader/`  | «احكِ لي ما يُتعبك.» والسطر تحته                                                                                       |
| `ServiceChoice/`  | «ما الذي تحتاجه؟» من محتوى الخدمات؛ رابط الطلب يختاره مسبقاً (`?s=ai&p=2`، `?project=tutubot`) ويقول من أين جاء الزائر |
