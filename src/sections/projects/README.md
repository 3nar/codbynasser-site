# المشاريع (`/projects/`)

الصفحة مطفأة الآن: لا رابط في الموقع يوصل إليها، وهي باقية كما هي. المشاريع في `src/content/projects/<اللغة>/`، ملف لكل مشروع (المجموعة، الترتيب، والشارة أو الهالة الصغيرة).

| القسم                                                                       | ما فيه                                               |
| --------------------------------------------------------------------------- | ---------------------------------------------------- |
| `ProjectsHero/`                                                             | «أعمال حقيقية، لا عروض تجريبية.» في هالة «works»     |
| `Works/`                                                                    | قسم الأعمال: المشاريع المفصّلة، ثم مجموعتا الفهرس    |
| `Featured/` (`FeatureCard.astro`، `art/TutuArt.astro`، `art/SberArt.astro`) | المشروعان المفصّلان، ولكل واحد رسمه (يُختار بمعرّفه) |
| `ProjectIndex/` (`ProjectRow.astro`، `MiniArt.astro`)                       | فهرس باقي الأعمال في مجموعتين، مع هالة صغيرة لكل صف  |
| `ToolList/`                                                                 | أدوات المشروع (بالحروف اللاتينية)                    |
