# الرئيسية (`/`)

الأقسام بترتيبها في `src/pages/[...locale]/index.astro`. نصوصها في `src/i18n/ui/<اللغة>/home.json`، والأبواب الثلاثة من محتوى الخدمات (`door` في ملف كل خدمة).
حركة القسم الذي يتحرك في ملف بجانبه: `Hero/hero.ts`، `Doors/doors.ts` (وأشكال الأبواب في `figures.ts`)، `WhyMe/why-me.ts`.

| القسم                              | ما فيه                                                                              |
| ---------------------------------- | ----------------------------------------------------------------------------------- |
| `Hero/`                            | الرجل وطيفه؛ الطيف يخرج مع التمرير ويصعد الغسق إلى ظلام المشكلات                    |
| `Problems/`                        | «هل يحدث هذا في مشروعك؟»: ست مشكلات، اثنتان من كل قسم، كل واحدة تقود إلى حلها       |
| (`components/effects/Spectrum`)    | شريط التدرّج من الأسود إلى الفاتح                                                   |
| `Doors/` (`Door.astro`)            | الأقسام الثلاثة أبواباً، والضوء السائل يأخذ شكل كل باب                              |
| `Industries/`                      | حلول على مقاس مجالك: ما يُبنى في كل مجال، بلا نتائج مدّعاة                          |
| `Work/`                            | مشروعان مختاران دليلاً. **موقوف** مع صفحة الأعمال ما دامت «قريباً» (`soonSections`) |
| `WhyMe/`                           | لماذا أنا: المكتب والقلم، وثلاث نقاط                                                |
| (`components/sections/ClosingCta`) | الخاتمة                                                                             |
