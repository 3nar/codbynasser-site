# codbynasser-site

كود موقع **cod by nasser** ([codbynasser.com](https://codbynasser.com)): الموقع الشخصي لناصر، مهندس ذكاء اصطناعي ومهندس برمجيات، يعرض خدماته لأصحاب المشاريع الصغيرة في ثلاثة أقسام: الذكاء الاصطناعي والبيانات، والبرمجيات والمنتجات الرقمية، والهوية والنمو الرقمي. بثلاث لغات: العربية على `/`، والإنكليزية على `/en/`، والروسية على `/ru/`.

_Source code of codbynasser.com, the personal site of Nasser, AI engineer and software engineer. Astro and GSAP, in Arabic, English and Russian._

> **الحالة:** قبل الإطلاق. كل الصفحات `noindex` حتى يوم النشر.

## التقنيات

- **[Astro 7](https://astro.build)** موقعاً ثابتاً: لا خادم ولا قاعدة بيانات. نموذج الطلب يكتب الرسالة ويفتحها جاهزة في واتساب أو البريد.
- **[GSAP](https://gsap.com)** وScrollTrigger للحركة، وتتوقف لمن طلب تقليل الحركة.
- **TypeScript** صارم، وCSS مكتوب باليد بجانب كل جزء (بلا Tailwind).
- **الاختبارات:** Vitest للمنطق، وPlaywright في Edge للتفاعل بعرض الحاسوب والموبايل.
- **ESLint وPrettier** لفحص الكود وتنسيقه.

## التشغيل

يحتاج Node 24 (`.nvmrc`)، وMicrosoft Edge لاختبارات التفاعل.

```bash
npm install
npm run dev
```

| الأمر                                               | ماذا يفعل                                             |
| --------------------------------------------------- | ----------------------------------------------------- |
| `npm run dev`                                       | خادم التطوير على `http://localhost:4321`              |
| `npm run build` · `npm run preview`                 | بناء الموقع (يفحص الترجمات أولاً) وعرض النسخة المبنية |
| `npm run check` · `npm run lint` · `npm run format` | فحص الأنواع، وفحص الكود، والتنسيق                     |
| `npm test`                                          | اختبارات المنطق                                       |
| `npm run test:e2e`                                  | اختبارات التفاعل في Edge                              |
| `npm run i18n:check`                                | يتأكد أن الإنكليزية والروسية فيهما كل نصوص العربية    |
| `npm run brand:assets`                              | يرسم الأيقونات وصور المشاركة من الشعار                |
| `npm run fonts`                                     | ينزّل الخطوط إلى الموقع حين يتغيّر خط أو وزن          |

الإعدادات المحلية في `.env` (انسخ `.env.example`). الموقع نفسه لا يقرأ أي سر.

## كيف يعمل

- **اللغات:** العربية هي الأصل، ومنها يأخذ كل نص مفتاحه، والإنكليزية والروسية تترجمان القيم بالمفاتيح نفسها. التصميم رُسم للعربية (من اليمين)، وصفحات اليسار إلى اليمين تعكسه كالمرآة: الصور، والضوء، والأسهم، والحركة.
- **الأنماط:** كل جزء له ملف CSS بجانبه، لكن لا جزء يستورده بنفسه: `src/styles/index.css` يستوردها كلها بترتيب ثابت، لأن ترتيب القواعد جزء من التصميم. مقاسات الخطوط بـ `rem`.
- **الحماية:** سياسة CSP بالبصمات في كل صفحة (`security.csp` في `astro.config.mjs`)، وترويسات الأمان في `public/_headers`، والخطوط من الموقع نفسه، فلا تُحمَّل الصفحة شيئاً من موقع آخر.
- **البحث:** عنوان ووصف لكل صفحة ولغة، والرابط الأساسي، وروابط اللغات، وبيانات منظمة (JSON-LD)، وخريطة الموقع. `src/lib/seo/pages.ts` يقرر وحده أي صفحة تظهر لمحركات البحث، و`SITE.searchable` يفتحها يوم الإطلاق.
- **الأقسام «قريباً»:** الأعمال والأكاديمية وللشركات موقوفة عن قصد (`soonSections` في `src/config/navigation.ts`)، وصفحة الأعمال مبنية وتنتظر.
